# Lumi Nail Studio Design

I need you to use the provided images and design inspiration as a starting point, but create a completely new and original website design for Lumi Sugar Nails.
Design & Development Requirements
Create a fresh, modern, premium design that fits the Lumi Sugar Nails brand.
Use the provided images and inspiration for direction, but do not simply replicate the reference designs.
Make sure all required website pages are fully designed and created.
Build the website in HTML with a focus on clean code, performance, and fast loading speeds.
Ensure the design is responsive and works properly across desktop, tablet, and mobile devices.
Location-Based Booking & Hero Section
The website will have three different Lumi Sugar Nails locations.
The Hero Section should feature three distinct location sections/cards, allowing visitors to immediately choose the location they want to visit.
When a visitor clicks on a specific location:
The selected location should open/display its dedicated information.
Show the services available at that location.
Show the staff/team members available at that location.
Display the business hours/timing for that location.
Allow the customer to proceed with the booking process specifically for that location.
Booking Form
The booking system should support multiple locations rather than treating all locations as one business.
The booking flow should allow the customer to select:
Location
Service
Staff member
Date
Available time
Any other required booking information
The available services, staff, and timings should dynamically correspond to the selected location.
Overall, the website should feel polished, premium, modern, and conversion-focused while keeping the user experience simple and easy to navigate.
